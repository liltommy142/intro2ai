# 🤝 Contributing Guide

## Branch Strategy

- `main`
- `develop`
- `feature/*`

---

## Commit Convention

| Prefix | Ý nghĩa |
|---------|----------|
| feat | Thêm tính năng |
| fix | Sửa lỗi |
| docs | Cập nhật tài liệu |
| refactor | Cải tiến mã |
| style | Định dạng |
| assets | Thêm tài nguyên |
| video | Cập nhật video |

Ví dụ

```bash
git commit -m "docs: update storyboard"
```

---

## Coding Style

- Đặt tên file rõ ràng.
- Không commit file tạm.
- Comment khi cần thiết.

---

## Documentation

Mọi thay đổi liên quan đến tài liệu phải được cập nhật vào file Markdown tương ứng.

---

## Pull Request

- Mô tả thay đổi.
- Kiểm tra lỗi trước khi merge.
- Đảm bảo không làm hỏng cấu trúc repository.
